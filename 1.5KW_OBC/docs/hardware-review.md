# 原理图审查与固件边界

## 已确认

1. U17 为 `GD32F303RET6`，HSE 为 8 MHz。
2. PFC 控制器为 `NCP1654BD133R2G`。
3. LLC 控制器为 `NCP4390DR2G`。
4. CAN 逻辑侧使用 3.3 V，隔离收发器为 `ISO1050`。
5. `OUT_RELAY`、`RELAY_PFC_EN_1` 和 `FAN_CTL` 都通过晶体管/光耦驱动，
   低电平是安全关闭值。
6. `HARD_FAULT_CLR` 带 3.3 V 上拉并连接锁存器的低有效清除端，因此
   正常保持高，清故障时输出低脉冲。
7. CV/CC 调节通过 `CV_PWM` 和 `CUR_PWM` 经 RC/运放转换为模拟控制量。

## 初版固件主动限制

- 不执行 PFC、LLC 或输出继电器的自动启动时序。
- 不允许 CAN 或串口命令开启功率级。
- ADC 先提供原始码值，不在缺少标定数据时换算成工程量。
- CAN 初始化代码保留，但默认不启用，直到波特率和报文表得到确认。
- 硬件故障输入一旦有效，立即重置所有受控输出到安全值。

## 上电前必须确认

| 项目 | 当前状态 | 建议确认方法 |
|---|---|---|
| PC11 与 PB15 同名 `LLC_EN` | 原理图存在冲突 | 用 AD 网表/PCB 飞线表核对 |
| `LLC_EN` 有效电平 | 逻辑链含 OR、反相器及二极管 | 仅上 3.3 V/12 V 辅助电源，断开高压，测 DRIVER_EN |
| `LLC_FAULT_CHECK` 有效电平 | 初步判断高为故障 | 人工触发比较器并测 PB12 |
| CV PWM 频率及电压映射 | 未给定 | 示波器 + 直流源标定 0/25/50/75/100% |
| CUR PWM 频率及电流映射 | 原理图注明 25 A 对应 0.5 V | 仍需实测斜率与零点 |
| ADC 增益/偏置 | 仅能由电阻初算，隔离放大器会引入增益 | 每路至少两点标定 |
| CAN 波特率和 ID | 原理图不包含协议 | 与上位机/整车协议表核对 |
| 系统主频 | HSE=8 MHz，PLL 配置未给定 | 确认使用 108 MHz 还是 120 MHz |
| NTC B 值 | 只标注 NTC/10K | 核对料号或 BOM |

## 建议低压联调顺序

1. 不接 AC、不接电池，仅上辅助电源。
2. 验证 3.3 V、复位、8 MHz 晶振和 SWD。
3. 烧录初版固件，确认 PFC/LLC/两只继电器均保持关闭。
4. 检查两路 PWM 为持续低电平，故障清除脚为高电平。
5. 逐路注入 0.2 V、1.0 V、2.0 V 检查 ADC 原始值。
6. 人工触发硬件故障链，验证 PB12 状态和安全关断。
7. 完成 `LLC_EN` 极性与同名网络冲突确认后，才允许修改
   `APP_ALLOW_POWER_ENABLE`。
