# 1.5 kW OBC

## 项目目标

开发一套额定功率为 1.5 kW 的车载充电机（OBC）。

## 初始架构

- 前级：PFC
- 后级：隔离型 LLC
- 控制与通信：待选型
- 输入、输出电压范围：待确认
- 效率、功率密度及散热目标：待确认

## 计划目录

- `hardware/`：原理图、PCB、BOM 与器件资料
- `firmware/`：MCU 固件及控制算法
- `simulation/`：PFC、LLC 与系统仿真
- `test/`：测试方案、数据和波形
- `docs/`：需求、架构、评审与开发排程
